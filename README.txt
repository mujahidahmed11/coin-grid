COIN GRID — SRIKANTOSTORE-INSPIRED DESIGN
=========================================
This is a visual/design recreation inspired by the reference's dark poster-style storefront, category navigation, game shelves, and selectable package tiles. It uses original COIN GRID branding and original CSS/SVG artwork, not SrikantoStore's private code, logo, or copyrighted game artwork.

FILES
- index.html
- styles.css
- app.js
- favicon.svg

PUBLISH
1. Extract this ZIP on your phone.
2. In GitHub repository coin-grid, replace index.html, styles.css, app.js.
3. Add favicon.svg.
4. Commit changes. Cloudflare Pages should automatically deploy.

CURRENT FUNCTIONALITY
- Select game category.
- Select Free Fire package tiles and see selected package/price.
- Membership filter tab.
- Search game tiles.
- WhatsApp order request with UID, server, package, payment and phone.
- Payment method labels for bKash, Nagad and Rocket.

IMPORTANT LIMITATIONS
This is a front-end order request, not a full e-commerce backend. It does not accept or verify payments, save customer orders, manage inventory, provide login/accounts, or include an admin dashboard. PUBG, Mobile Legends, Valorant and other game prices are not invented; customers can request them via WhatsApp until you add confirmed prices.
